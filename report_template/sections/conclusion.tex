\section{Conclusion}

This report detailed the use of a custom UDP probe to analyze an emulated network path across two experiments. In the first experiment, the RTT exhibited a bimodal pattern with a stable baseline latency around 30 ms and occasional queueing spikes exceeding 290 ms. Packet loss reached 11.7\%, occurring fairly consistently throughout the 20-minute run. A secondary variable-packet-size experiment estimated the actual bottleneck capacity to be 15.51 Mbps, which aligns well with the expected 20 Mbps limit.
