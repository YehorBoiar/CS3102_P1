\section{Conclusion}

This experiment measured the packet loss, delay, and end-to-end data rate of a network path using probe packets and RTT-based analysis. The measured loss rate of \textbf{9.83\%} closely matched the emulator's configured 10\% packet loss probability, indicating that the probing method accurately captured random packet drops.

The observed median RTT values of approximately \textbf{32\,ms} were also consistent with the emulator's configured delay of roughly 30\,ms. This suggests that the probing approach provides a reliable estimate of end-to-end delay under the given experimental conditions.

Using the difference in RTT between small and large probes, the end-to-end data rate was estimated to be \textbf{21.39\,Mbps}. Although this value slightly exceeds the expected upper bound of 20\,Mbps specified for the emulator, it remains of the same order of magnitude and likely reflects measurement noise and simplifying assumptions in the RTT-based estimation method.
