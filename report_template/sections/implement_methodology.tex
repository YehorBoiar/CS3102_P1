\section{Implementation and Experimental Methodology}

The probe program was implemented using the provided code from the lecture week 3. The only part that I've reused were files: \textbf{UdpSocket.c/h}, and I took inspiration from \textbf{udp-client-2} that was reading a string from the terminal and sending that as a UDP packet of array of characters.

\subsection{Transmission Control and Concurrency}
The assignment asks for one probe per second and permits only one outstanding probe at any given time. To enforce this, the app uses \texttt{poll()} system call:
\begin{enumerate}
    \item \textbf{Transmission:} For each iteration, a \texttt{ProbePacket\_t} containing a sequence number, a monotonic transmit timestamp, and a magic value is constructed and sent to the remote reflector via UDP.

    \item \textbf{Reception Window:} The socket is monitored using \texttt{poll()} with a timeout of $1$ second to detect an incoming reflected datagram.

    \item \textbf{Classification:} If a correctly sized packet with a valid magic number is received within the timeout window, the RTT is computed and the probe is logged as \texttt{SUCCESS}. If no packet arrives before the timeout, the probe is marked as \texttt{LOST}. Any malformed or invalid packet is classified as \texttt{ERROR\_OR\_CORRUPT}.
\end{enumerate}

\subsection{Data Collection Setup}

Two datasets were collected.

\subsubsection{\texttt{fullpe\_data.csv}}

1200 probes were sent over approximately 20 minutes, with probe sizes alternating between 28 and 1400 bytes. The sender ran on \textbf{pc1-008-l}, targeting \texttt{slurpe-5} on \textbf{pc1-007-l} with the \texttt{fullpe} flag enabled.

\begin{verbatim}
yb33@pc1-007-l:~/Documents/CS3102/coursework1 $ ./slurpe-5 rx fullpe pc1-008-l pc1-008-l
** path emulation **
pe_seed: 24628 (unix uid)
delay:   30 ms (30000000 ns)
loss:    10 % (P{loss})
rate:    16 Mbps
ns_byte: 500 ns
** ---- **** ---- **

** slurpe running with PID 248371 ...
** flags: rx=on fullpe=on hexdump=off delay=on loss=on rate=on
** hostinfo: pc1-008-l (138.251.28.252) | pc1-008-l (138.251.28.252) | port=24628
** configuration: max_msg_size=1400 bytes | max_q_size=128 packets
\end{verbatim}

The program outputs structured CSV data using \texttt{printf}. A header is printed at startup, and each probe result is written as a comma-separated record:

\begin{verbatim}
printf("sequence_number,rtt_ms,bytes_received,status\n");
\end{verbatim}

The output was redirected to \texttt{fullpe\_data.csv} for analysis.
